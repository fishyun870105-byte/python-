**🐍 Python 實用小工具集**
這裡收錄了Python 桌面小工具實作練習：

### 1. 🌐 即時語音翻譯懸浮小工具 (`livetranslate_app.py`)
**介紹**：基於 Python 與 Faster-Whisper 撰寫的懸浮即時翻譯桌面工具，能即時擷取系統音訊並轉譯為繁體中文。\n
**特色**：即時語音辨識、動態懸浮字幕、自動累積歷史對照字幕。

### 2. 🏥 健康衛教語音小幫手 (`health_app.py`)
**介紹**：結合 CustomTkinter 暖色質感介面、語音辨識與 YouTube 自動播放的健康衛教工具。\n
**特色**：支援語音查詢健康主題（如血壓、血糖、膝蓋），並自動跳出對應的衛教影片與重點提示。
